# Journal de l'école

Journal numérique écrit à plusieurs, puis distribué par un lien qui délivre un nombre exact d'exemplaires. Projet d'évaluation « Développement web et cloud ».

Cette version tourne entièrement sur ta machine. Les documents, les parutions et le compteur d'exemplaires restent dans le navigateur. Aucune requête n'est envoyée à AWS.

Les décisions du sujet sont dans [`docs/BRIEF_CURSOR.md`](docs/BRIEF_CURSOR.md).
